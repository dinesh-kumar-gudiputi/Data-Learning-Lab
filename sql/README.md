# SQL

Two parts: questions to practise and topics to study.

| Folder | What it holds |
| --- | --- |
| [`problem-solving/`](problem-solving/README.md) | Daily coding questions in `easy/`, `medium/` and `hard/`, finished ones in `solved/`, older LeetCode solutions in `earlier-solutions/` |
| [`learning/`](learning/README.md) | Study material: 21 SQL topics, analytics, cleaning, data warehouse, ETL and performance examples on a demo MySQL database |

```text
sql/
├── problem-solving/
│   ├── easy/  medium/  hard/    assigned questions + index
│   ├── solved/                  finished questions, one folder per level
│   └── earlier-solutions/       12 LeetCode solutions from before the daily routine
└── learning/                    topics and examples, in study order
```
