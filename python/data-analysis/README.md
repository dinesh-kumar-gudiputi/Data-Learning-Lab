# Data analysis with Python

Reference work for the core analysis libraries. Open the notebooks in Jupyter or VS Code.

## Notebooks

| # | Notebook | Covers |
| ---: | --- | --- |
| 1 | [NumPy](notebooks/01_numpy.ipynb) | Creating arrays, indexing, array operations, adding axes |
| 2 | [pandas](notebooks/02_pandas.ipynb) | Series and DataFrames, locating rows, loading files, missing values |
| 3 | [Pokemon (pandas tutorial)](notebooks/03_pokemon_pandas.ipynb) | Loading, sorting, adding and deleting columns, filtering, exporting |
| 4 | [Seaborn](notebooks/04_seaborn.ipynb) | Numerical, categorical, distribution and regression plots |
| 5 | [Plotly and Cufflinks](notebooks/05_plotly_cufflinks.ipynb) | Interactive line, scatter, bar and stacked charts, offline mode |

Some notebooks read datasets from a Kaggle download path. Download the dataset first or point `read_csv` at your own copy.
