## Folders

| Folder | What it holds |
| --- | --- |
| `easy/`, `medium/`, `hard/` | Assigned questions, stored once under their LeetCode difficulty, plus an index of the level |
| `solved/easy/`, `solved/medium/`, `solved/hard/` | Finished questions. Move a file here when it is solved and reviewed |

Question numbers are one sequence for the whole Python track and keep counting across levels. The source platform's problem ID is inside each file.

## Run a question

Use Python 3 with the VS Code Python extension. A `.venv` keeps dependencies separate. Most questions need only the standard library, the pandas ones need `pandas`.

Function stubs raise `NotImplementedError` until you implement them. Running the file alone does not test anything, so call your function with the examples from the file header or add your own checks.
