# Python practice

Daily Python questions for data analyst and data engineering roles, plus reference notebooks for the data-analysis libraries.

## Folders

| Folder | What it holds |
| --- | --- |
| [`easy/`](easy/README.md), [`medium/`](medium/README.md) | Assigned questions, stored once under their LeetCode difficulty |
| `easy_solved/` | Questions already solved. Move a file here when it is done |
| [`data-analysis/`](data-analysis/README.md) | NumPy, pandas, seaborn and plotly notebooks, plus two small EDA exercises |

```text
python/
├── easy/             assigned easy questions + index
├── easy_solved/      finished easy questions
├── medium/           assigned medium questions + index
└── data-analysis/    notebooks and exercises
```

Question numbers are one sequence for the whole Python track and keep counting across difficulty levels. The source platform's problem ID is inside each file.

## Run a question

Use Python 3 with the VS Code Python extension. A `.venv` keeps dependencies separate. Most questions need only the standard library, the pandas ones need `pandas`.

Function stubs raise `NotImplementedError` until you implement them. Running the file alone does not test anything, so call your function with the examples from the file header or add your own checks.
